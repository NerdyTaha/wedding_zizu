# Media Assets

Put your media assets here so that the code can access them.

1. **Background Audio**: Add your background mp3 file here and name it exactly `bg_audio.mp3`.
2. **Animation Audio**: Add your hero section animation mp3 file here and name it exactly `animation_audio.mp3`.
3. **Hero Sequence Images**: Create a subfolder named `hero_sequence`. Put your sequence of images inside it, named `frame_0.png`, `frame_1.png`, `frame_2.png`, etc. You can adjust the file names and the total number of frames by editing `src/components/HeroSection.jsx`.
4. **Slideshow Images**: You can name them `slide_1.jpg`, `slide_2.jpg`, etc., and update the array in `src/components/SlideshowSection.jsx`.
